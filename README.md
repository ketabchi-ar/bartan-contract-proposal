# قرارداد و پروپوزال رسمی وب‌سایت فروشگاهی برند برتن (BRATAN)
### آژانس دیجیتال پالت (اردلان کتابچی) × سرکار خانم ملیح کرمی‌طلب

این پروژه شامل وب‌اپلیکیشن تعاملی قرارداد و پروپوزال رسمی برای طراحی و پیاده‌سازی وب‌سایت فروشگاهی اختصاصی دست‌سازه‌ها و دکمه‌های نقره برند **برتن (BRATAN)** می‌باشد.

---

### ویژگی‌های کلیدی این قرارداد آنلاین:
1. **مفاد رسمی و حقوقی جامع در ۱۰ ماده:**
   - موضوع قرارداد، مشخصات کارفرما و مجری.
   - نیازمندی‌های زیرساختی: هاست، دامنه، درگاه‌های شاپرکی، درگاه پیامکی، اینماد و پرونده مالیاتی با همراهی و راهنمایی تجربی پالت.
   - اشاره به اتصال فروشگاه به حسابداری حسابفا بر پایه امکانات رسمی ووکامرس.
   - مبلغ ۳۰ میلیون تومان با امکان پرداخت ۵۰٪ نقد و ۵۰٪ هنگام تحویل، یا اقساط ۴ ماهه با دیجی‌پی.
   - زمان تحویل ۲۱ روز کاری و پشتیبانی ۴ ماهه فنی و امنیتی رایگان پس از تسویه.

2. **پیوست شماره ۱ (UI / دیزاین‌سیستم برتن):**
   - گالری تعاملی لایت‌باکس با امکان بازبینی اندازه کامل طرح‌های صفحه اصلی، آرشیو، تک‌محصول، سبد خرید، لاگین و تسویه‌حساب به همراه دیزاین‌سیستم رنگی (`#2D2D2D`, `#8C897E`, `#F7F6F4`).

3. **پیوست شماره ۲ (اکوسیستم خدمات آژانس پالت):**
   - معرفی فرصت‌های توسعه و سیستم‌های اختصاصی آنلاین/آفلاین، اتوماسیون، CRM و تبلیغات شبکه‌های اجتماعی.

4. **سیستم احراز هویت OTP و امضای الکترونیک:**
   - متصل به وب‌سرویس SMS.ir (الگوی شماره ۵۱۹۸۳۰) با قابلیت احراز هویت شماره کارفرما (09388873996).
   - ریدایرکت خودکار به صفحه محصول در سایت پالت جهت تکمیل پرداخت نقدی یا اقساطی دیجی‌پی: `https://palette.agency/bartan-website`.

5. **طراحی واکنش‌گرا و قابلیت پرینت / خروجی PDF:**
   - بهینه‌سازی شده با Print CSS برای دریافت نسخه تمیز قرارداد جهت بایگانی فیزیکی.
